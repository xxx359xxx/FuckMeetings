# FuckMeetings 1.1.0

## Тренировка собеседований

- Создавайте тренировки из своих вопросов, `.txt` и вопросов выбранной ИИ-модели. Перед началом можно проверить и изменить список, порядок и количество вопросов.
- Сохраняйте наборы локально, повторно открывайте их и передавайте другим людям через файл `.fmquestions.json`.
- Отвечайте текстом или через распознавание речи. Редактор кода поддерживает подсветку JavaScript, TypeScript, Python, SQL, Java, C++, Go, Rust, JSON, HTML и CSS.
- Используйте подсказки и уточняющие вопросы ИИ. После тренировки доступен разбор каждого ответа, история и повторное прохождение вопросов.
- Прогресс, ответы и наборы хранятся на вашем компьютере. Ручная тренировка работает без ИИ-провайдера; для генерации и разбора его нужно настроить.

Оценка ответов — мнение модели. Код и SQL не выполняются и не проверяются тестами; корректность решения не гарантируется.

## Установка и обновление

В выпуске доступны установщик Windows x64 и образ macOS для Apple Silicon. Приложение поддерживает обновление с 1.0.7; перед установкой сохраните важные данные обычным для вашей системы способом.
