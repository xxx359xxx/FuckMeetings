# FuckMeetings 1.1.1

Исправления раздела **Тренировка**:

- Редактор ответов теперь использует подходящие цвета фона, текста и подсветки синтаксиса в тёмной теме.
- Черновик настройки тренировки и выбранная сессия сохраняются при переходе между разделами и после перезапуска приложения.
- При возврате к списку, сохранении ответа или досрочном завершении приложение дожидается распознавания речи. Текущий текст ответа сохраняется; ошибка распознавания показывается до перехода к следующему вопросу.

Тренировка по своим вопросам по-прежнему работает без ИИ-провайдера. Для генерации, подсказок и разбора нужен настроенный провайдер, а для голосового ответа — транскрибатор.
